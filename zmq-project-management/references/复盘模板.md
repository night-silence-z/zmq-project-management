# 可选复盘模板

仅在用户要求、项目跨度较长或结论具有明确复用价值时使用。普通里程碑不自动生成复盘。

## 生成原则

- 区分事实、用户明确表达和推断。
- 单次反馈不写成长期偏好。
- 缺失证据标记未知，不补写成事实。
- 聚焦可复用的方法、风险与资产，不复述完整项目流水。

## 输出结构

1. **目标与结果**：原目标、最终结果、未完成或降级项。
2. **关键决策**：改变项目方向的决策及依据。
3. **有效做法**：可复用的方法、工具和验证方式。
4. **主要摩擦**：执行侧可改善的问题及避免方式。
5. **资产与去向**：可复用材料、状态和建议保存位置。
6. **后续建议**：仅列有证据支持、可执行的建议。

需要记录协作偏好时，为每条标注适用条件和证据来源；未经用户确认，不同步到全局记忆或规则。
